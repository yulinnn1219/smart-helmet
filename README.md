# 智能头盔本地前端

本项目从空目录实现六类骑行页面，面向树莓派 Wi-Fi 局域网或本地热点部署。默认运行模拟数据，真实采集、识别、规则判断、控制和存储由树莓派完成。当前没有数据库或硬件连接。

## 本地运行

安装 Node.js 20 或更高版本后，在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:5173 。项目没有第三方运行依赖，无需安装 npm 包、下载字体或连接在线地图。请通过 HTTP 服务访问，浏览器直接双击 index.html 无法正常加载 ES 模块。

Windows 下也可双击项目中的“启动预览.cmd”。服务启动后访问 http://127.0.0.1:5173；已有预览服务运行时无需重复启动。

当前 Codex 工作环境也可以使用已配备的 Node.js，在 PowerShell 中运行：

```powershell
Set-Location -LiteralPath 'D:\desktop\华五\smart-helmet'
& 'C:\Users\17147\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' server.mjs
```

手机访问开发预览时，将服务绑定局域网地址：

```powershell
$env:HOST='0.0.0.0'
npm start
```

手机与电脑连接同一局域网，访问电脑的局域网 IP 与端口 5173。树莓派部署方式见 [前后端对接说明](docs/前后端对接说明.md)。

## 页面和数据

| 页面 | 内容 |
| --- | --- |
| 骑行状态总览 | 当前风险、触发原因与安全语音提醒优先，随后是速度、位置、行程时间、设备与环境，连接和模块状态放在下方 |
| 主动安全 | 独立展示摄像头目标与超声距离，显示树莓派联合风险、画面采集时间、距离趋势及主动安全事件 |
| 事故与异常 | IMU 判定、安全事件类型和日期筛选、事件详情及行程关联 |
| 骑行辅助 | 光照、灯光模式和控制来源、模拟语音指令、执行记录与反馈阶段 |
| 舒适体验 | 温湿度、趋势、风扇模式、来源和触发原因 |
| 行程记录 | 行程选择、GPS 轨迹、里程、时长、平均与最高速度，以及关联安全事件 |

顶部场景选择提供正常、风险提醒、GPS 未定位、传感器异常、数据过期、连接断开、加载中、无数据八种模拟状态。切换场景会重置该场景的演示指令和手动模式。模拟数据只在内存中存在，刷新浏览器会重置。

在骑行辅助页模拟“打开风扇”或“关闭灯光”后，模式保持手动；模拟“恢复自动”后重新显示规则控制。传感器异常场景可验证执行失败。加载、空数据、过期、断连场景禁止发送演示指令。这里没有浏览器录音功能，实际语音识别应在树莓派运行。

“数据设置”可切换到同源树莓派接口模式。本地预览服务对 /api 请求返回 501 待对接错误，页面会显示断连或查询失败，绝不使用模拟结果替代真实请求。

## 项目结构

```text
smart-helmet/
  dist/                    可直接部署的前端静态资源
    index.html             页面外壳和导航
    styles.css             本地样式和手机布局
    js/config.js           轮询周期和集中管理的过期阈值
    js/domain.js           状态语义、格式化和协议边界
    js/data.js             统一数据访问层、HTTP 适配器和共享数据存储
    js/mock.js             同结构模拟适配器和场景
    js/ui.js               公共组件与六类页面
    js/app.js              路由、交互、弹窗和可选浏览器工具
  server.mjs               开发静态服务，不是树莓派后端
  tests/data.test.mjs       数据与安全展示规则验证
  checks/check.mjs          语法、本地资源和离线样式检查
  docs/                    对接说明、类型和 JSON 示例
```

技术栈采用原生 HTML、CSS、JavaScript ES 模块，以及仅用于本地预览的 Node.js 静态服务。无需构建，部署只需复制 dist。全站没有外部脚本、字体和地图 SDK；关闭互联网后，在本地网络和树莓派服务仍可达的前提下可使用核心页面。Wi-Fi 本身断开时，已打开的页面会标注断连与旧值，不保证断连后的首次打开或浏览器重载可用。

已执行的浏览器和数据验证范围见 [检查记录](docs/检查记录.md)。测试只验证前端与模拟逻辑，不代表完成硬件联调。仍待接入的功能包括实际摄像头画面、树莓派 HTTP 接口、本地数据库、安全规则、真实语音识别与播放，以及可用的离线底图和硬件反馈。
